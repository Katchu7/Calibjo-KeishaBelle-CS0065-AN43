## Project Overview
This project implements a multi-agent random walk simulation in Python using the **AgentPy** framework and visualizes the agent trajectories using **Matplotlib**. 

It fulfills the laboratory requirements, including:
1. **Interactive Console Inputs:** Prompting the user to specify the number of agents, grid dimensions, and simulation steps.
2. **Path Tracking:** Recording and displaying the historical trajectory of each agent on the grid[cite: 1].
3. **Modified Movement Rules:** Introducing a preferred directional bias (leaning towards the top-right quadrant) instead of purely uniform random movement[cite: 1].
4. **Final Position Analysis:** Printing out the exact final coordinate and total step count for every agent upon simulation completion[cite: 1].
